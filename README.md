# Security Operations Center (SOC) Threat Dashboard (`cyber-threat-dashboard`)

A real-time cybersecurity incident monitoring and threat intelligence dashboard built with React, TypeScript, Vite, and Tailwind CSS. Provides security analysts with interactive alert feeds, threat severity categorization, IP lookup auditing, and SOC incident resolution workflows.

## Features

- **Real-Time Alert Feed:** Simulated streaming security alerts (Brute Force, Port Scan, Malware Signatures, Unauthorized Access).
- **Interactive SOC Workflow:** Filter alerts by severity (Critical, High, Medium, Low), acknowledge events, and resolve incidents.
- **IP Threat Intelligence:** Search and inspect remote source IPs and threat origin metadata.
- **Security Metrics:** High-level key performance indicators (Active Alerts, Mean Time to Detect, Threat Vector Breakdown).
- **Strong Type Safety:** Built with strict TypeScript interfaces and data contracts.
